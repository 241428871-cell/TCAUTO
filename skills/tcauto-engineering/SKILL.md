# TCAUTO 工程习惯

开始新项目或工程工作前，读取 [跨项目工程习惯原文](references/跨项目工程习惯.md)，再读取当前项目入口与交接。将适用约定用于实际工作，不把历史示例、计划或来源项目的授权当作当前任务授权。

原文来自用户指定的《跨项目工程习惯(4).md》，按字节保留，不改写、不删节。原文提及的项目专题路径是该项目的例子；按目标项目实际位置解析，不要求复制来源工程的目录或状态。

为新项目按原文建立适用的 `AGENTS.md` 与 `CLAUDE.md` 入口，指向 TCAUTO 和项目交接。已有项目沿用现有入口和目录，只补充缺失的引用，不制造重复文档。

长任务、定时续接与多 Agent 审查转到同一技能集的 `tcauto`。创建子 Agent 时必须显式填写 `model` 为已核实的主会话当前模型完整标识，不省略或依赖默认继承；用户另有最新明确模型选择时按其执行。思考深度独立按任务仅选 `low`、`medium`、`high`、`xhigh`，不使用 `max`、`ultra`；用户最新要求优先于原文中的历史示例。
